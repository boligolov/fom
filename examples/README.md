# Examples

This directory contains larger FoM examples intended to exercise the representation as a whole.

- `story-001-platform.fom` — language-independent short-fiction source graph with ambiguity, nested models, fixed unknowns, disclosure constraints, symbolic mapping, and reader trajectory.
- `winnie-001.fom` — text-first extraction centered on correct instruction / wrong rationale, humor, reinterpretation, and partial self-awareness.

These are exploratory FoM Text files. Their purpose is to pressure-test the language and model, not to define final syntax.
