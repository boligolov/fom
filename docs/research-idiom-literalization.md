# Idiom literalization and semantic re-entry

Status: research note

Some wordplay depends on a signal first activating a conventional non-literal construction and then reactivating part of that same signal literally.

This differs from ordinary ambiguity and from simple metaphor.

## 1. Example

```
"Ничто так не красит человека, как перекись водорода."
```

A conventional figurative reading of "красит человека" is roughly:

```
makes a person look better / improves their image / reflects well on them
```

The punchline activates a literal chemical-coloring/bleaching interpretation.

The joke requires both structures:

1. conventional idiomatic / figurative interpretation;
2. literal physical interpretation.

## 2. Important distinction

This is not merely:

```
word has meaning A
word has meaning B
```

The first reading is constructional.

The relevant unit is larger than a single lexical item.

Therefore FoM should allow SEMIOTIC mappings from:

- a lexical item;
- a phrase;
- a construction;
- a larger signal substructure;

to semantic subgraphs.

## 3. Semantic re-entry

The later context does not delete the conventional reading.

Instead:

```
reading A initially dominant
reading B later activated
A remains recoverable
contrast A <-> B produces humor
```

This is the same broad multi-meaning architecture discovered in the cannibal example, but with a different source of duality:

```
cannibal example:
    competing frames licensed by same construction

idiom literalization:
    conventional constructional meaning + literal compositional re-entry
```

## 4. Signal locus

The same signal fragment must participate in both mappings.

A realization that expresses the two readings using unrelated sentences may preserve propositional content but lose the wordplay function.

Therefore a useful realization constraint is:

```
PRESERVE_FUNCTION:
    same-or-functionally-linked signal locus
    supports both readings
```

This is stronger than preserving A and B independently.

## 5. Conclusion

No new primitive is required.

FoM needs addressable signal fragments and many-to-many SEMIOTIC mappings between signal substructures and semantic subgraphs.
