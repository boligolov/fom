# Questions, alternatives, and open-question state

Status: research note

Questions are not well modeled as propositions with a question mark.

They transform conversational/shared state by introducing or foregrounding a set of alternatives and requesting resolution.

## 1. Example

```
"Кто пришёл?"
```

The signal does not assert:

```
someone came
```

in every use, though ordinary contexts may presuppose or suggest this.

Its central operation is closer to:

```
open question Q
domain: relevant people
issue: which bindings satisfy came(?x)
request receiver to resolve Q
```

## 2. Open question as state

An open question may be represented as an addressable NODE/SUBGRAPH plus constraints over alternatives.

Conceptually:

```
QUESTION Q {
    pattern P(?x)
    alternatives generated by bindings of ?x
    status: OPEN
}
```

Opening the question is a DELTA to conversational/shared state.

Answering the question is another DELTA:

```
OPEN -> RESOLVED / PARTIALLY_RESOLVED / CLOSED_WITHOUT_ANSWER
```

No QUESTION Core primitive is required if questionhood is represented as a typed NODE plus DELTA/CONSTRAINT.

## 3. Polar questions

```
"Иван пришёл?"
```

Alternative set:

```
P
NOT P
```

The question need not commit the speaker to either alternative.

## 4. Biased questions

```
"Разве Иван пришёл?"
```

The same headline alternative set may be present, while speaker expectation favors NOT P.

Thus question content and stance are separate.

Possible structure:

```
QUESTION:
    {P, NOT P}

speaker expectation:
    NOT P preferred
```

## 5. Alternative questions

```
"Иван или Пётр пришёл?"
```

The signal explicitly introduces an alternative set.

FoM should preserve whether alternatives are:

- exhaustive;
- non-exhaustive;
- mutually exclusive;
- merely salient candidates.

These properties are constraints, not assumptions.

## 6. Partial answers

A response can reduce an alternative set without uniquely resolving it.

Example:

```
Q: Кто пришёл?
A: Кто-то из бухгалтерии.
```

This changes the question state:

```
candidate set narrows
question remains partially open
```

This is a natural DELTA over the question's alternative space.

## 7. Relevance to discourse

Open questions can organize discourse even when never explicitly spoken.

A narrative may create:

```
Q: why did she leave?
```

and then delay its resolution.

This connects question state directly to trajectory/disclosure machinery.

## 8. Conclusion

FoM should represent questions as:

```
typed question object
+
pattern / alternative set
+
conversational-state DELTA
+
resolution constraints
+
speaker stance where relevant
```

No additional semantic Core primitive is currently required.
